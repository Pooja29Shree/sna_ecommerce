  Scraped on : August 2026

HOW IT WAS COLLECTED
---------------------
  Tool used  : Python 3 — requests library + BeautifulSoup (bs4)
  Script     : d:\sna\real_scraper.py

  Methodology:
    1. Seed URL: Started at a single product page (https://scrapeme.live/shop/bulbasaur/)
    2. BeautifulSoup parsed the HTML to extract:
         - Product Name  (HTML selector: h1.product_title)
         - Price         (HTML selector: p.price)
         - Category      (HTML selector: span.posted_in a)
    3. The "Related products" HTML section was parsed to extract recommended
       product URLs (selector: section.related.products a.woocommerce-LoopProduct-link)
    4. Each recommended product URL was added to a queue.
    5. The scraper visited each queued product and repeated the process.
    6. Traversal stopped when all reachable products were visited.

SOURCE

  File       : meta_Video_Games.json.gz
  Collected  : Originally scraped by UCSD researchers (Julian McAuley et al.)
               from Amazon.com. Data covers products up to year 2014.
  Paper Ref  : "Ups and Downs: Modeling the Visual Evolution of Fashion Trends
                with One-Class Collaborative Filtering" — McAuley et al., WWW 2015

HOW IT WAS COLLECTED (from source)
------------------------------------
  Original collection: UCSD researchers crawled Amazon.com product pages,
  extracting metadata and the "Customers who bought this also bought" section
  to build the recommendation graph. The full metadata was released publicly
  on the Stanford SNAP website.

HOW IT WAS PROCESSED IN THIS PROJECT
--------------------------------------
  Tool used  : Python 3 — gzip (standard library) + ast.literal_eval + pandas
  Script     : d:\sna\process_amazon_dataset.py

  Methodology:
    1. The .json.gz file was streamed line-by-line (to save RAM) using gzip.open()
    2. Each line is a Python dictionary string (not standard JSON) representing
       one product's metadata.
    3. ast.literal_eval() safely parsed each line into a Python dictionary.
    4. The following fields were extracted from each record:
         - asin              -> Product ID
         - title             -> Product Name
         - price             -> Price in USD
         - categories[0][-1] -> Deepest sub-category label
         - related['also_bought'] -> List of recommended product ASINs (EDGES)
    5. HTML tags were stripped from text fields using regex.
    6. Two DataFrames (nodes, edges) were built and exported as CSV files.
    7. Duplicates were removed from both nodes and edges.

  HOW THESE DATASETS MAP TO THE PAPER
================================================================================

  Paper Concept               | This Dataset Field
  ----------------------------|--------------------------------------------
  Product node                | Row in amazon_nodes.csv
  Recommendation link (edge)  | Row in amazon_edges.csv
  Product ID                  | "Product ID" column (ASIN)
  Network Size                | Total number of nodes in a connected component
  AvgCC (Avg Clustering Coeff)| Computed from the edges using networkx

  Price                       | "Price (USD)" column
  Category (homogeneity)      | "Category" column


================================================================================
  HOW TO USE THESE FILES
================================================================================

  1. TESTING (small dataset):
     - Load scraped_nodes.csv and scraped_edges.csv in Python or Gephi
     - Verify your metric calculations manually
     - Confirm the network loads and renders correctly

  2. MAIN ANALYSIS (large dataset):
     - Load amazon_nodes.csv and amazon_edges.csv
     - Build a directed graph using networkx: nx.from_pandas_edgelist(...)
     - Compute metrics: nx.average_clustering(), nx.pagerank(), etc.
     - Merge computed metrics back to nodes for regression analysis

  3. GEPHI IMPORT:
     - Open Gephi > File > Import Spreadsheet
     - Import amazon_nodes.csv as "Nodes table"
     - Import amazon_edges.csv as "Edges table" (select "Directed")
